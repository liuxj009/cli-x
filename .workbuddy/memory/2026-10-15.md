## 修复 cli-demo：`my-cli create <name>` "没反应"

**现象**：执行 `my-cli create my-first-demo` 无有效输出，终端只出现一个 `{}`。
（并非命令不存在 —— `my-cli` 已通过 npm link 全局可用。）

**根因**：`bin/index.js` 中写成 `.command('create ')`，commander 只解析出命令名，**没有注册任何参数**，
于是 action handler 收到的第一个参数是 `this.opts()`（空对象 `{}`），而不是项目名。
`lib/create.js` 里的 `console.log(projectName)` 便打印出 `{}`。

**修复**：`.command('create ')` → `.command('create <projectName>')`（同时去掉尾随空格）。
修复后 `my-cli create my-first-demo` 正常输出 `my-first-demo`。

**实测对比**（commander 11.1.0）：

| 命令声明 | handler 收到的参数 |
| --- | --- |
| `'create '` | `{}` \| `<Command create>` |
| `'create <projectName>'` | `"my-first-demo"` \| `{}` \| `<Command create>` |

结论：commander 的 `.command()` 里，`<arg>` / `[arg]` 是**参数声明**；不声明则 handler 永远拿不到该值。
handler 固定签名为 `(arg1, arg2, ..., options, command)`。
